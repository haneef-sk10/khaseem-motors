KHASEEM MOTORS WEBSITE — STARTER PROJECT

FILES
- index.html: homepage
- privacy.html: separate privacy policy page
- styles.css: layout, typography, colours and responsive design
- script.js: mobile navigation and footer year

DESIGN CHOICES
- Light background, charcoal text and restrained blue
- Square/rectangular buttons
- No fabricated reviews, customer counts, prices, model stock claims or opening hours
- No contact form, analytics or advertising trackers included
- Phone, WhatsApp and Google Maps links use the details supplied for this project

IMPORTANT BEFORE PUBLISHING
1. Replace the showroom-photo placeholder with a real photo you own or have permission to use.
   Suggested path: images/showroom.jpg
2. To use that image, create an "images" folder, add your photo as "showroom.jpg", then in
   styles.css replace the .photo-placeholder background declaration with:
   background: linear-gradient(0deg, rgba(10,17,24,.30), rgba(10,17,24,.05)), url("images/showroom.jpg") center / cover no-repeat;
   Keep suitable text contrast, or remove the placeholder text when using the photo.
3. Ask the showroom owner to verify the authorized-dealer wording, contact details, Maps link,
   and privacy policy before the site goes live.
4. Add an exact street address and opening hours only after confirming them.
5. Never publish customer names, phone numbers, photos or testimonials without permission.
6. Check the live website on a phone and computer after deployment.

LOCAL PREVIEW
- Extract this ZIP to a folder.
- Open the folder in VS Code.
- Install the "Live Server" extension by Ritwick Dey (or use VS Code's built-in/simple local
  preview option if available).
- Right-click index.html and choose "Open with Live Server".
- Open privacy.html to check the separate privacy page.

FREE DEPLOYMENT PLAN
- Create a GitHub repository to store these website files.
- Connect that repository to Cloudflare Pages for deployment.
- For a plain static HTML/CSS/JS site, no build command is needed and the output directory is "/".
- Cloudflare Pages will provide a pages.dev address on the free tier, subject to current plan terms.
- A custom domain normally requires purchasing a domain name. Free plan features and limits can change.

This is a starter website, not yet published. The photo area is deliberately a placeholder so it
does not pretend to show a real Khaseem Motors showroom or an actual Bajaj motorcycle.
